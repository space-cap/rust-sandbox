# Rust Game 04: 게임 라이프사이클(States), BGM & UI HUD 🎵🧱

Bevy 게임 엔진의 **상태 머신(`States` 트레이트)**을 완벽히 적용하여 `Menu` $\leftrightarrow$ `Playing` $\leftrightarrow$ `Paused` $\leftrightarrow$ `GameOver` $\leftrightarrow$ `Victory` 생명주기를 완벽히 제어하고, **패들 가변 반사각(스킬샷) 물리**와 **절차적 8-bit 효과음(SFX)**을 탑재한 정통 아케이드 벽돌깨기(Breakout) 게임입니다.

---

## 🎮 주요 기능 및 학습 포인트

1. **게임 생명주기 상태 머신 (`States`, `in_state`, `OnEnter`, `OnExit`)**:
   - `Menu`: 시작 메뉴 화면 (Space/Enter로 시작)
   - `Playing`: 공과 패들이 움직이고 벽돌이 파괴되는 실시간 물리 루프 (P로 일시정지)
   - `Paused`: 게임 물리 연산이 완전히 정지되고 반투명 안내 오버레이 노출 (P/Space로 복귀)
   - `GameOver`: 공을 놓쳐 3개의 목숨을 모두 소진했을 때의 게임 오버 화면 (R로 재시작)
   - `Victory`: 40개의 모든 컬러 벽돌을 격파했을 때의 승리 클리어 화면 (R로 재도전)
2. **패들 가변 반사각(스킬샷) 물리 공식**:
   - 공이 패들의 정중앙에 맞으면 수직으로 튕기지만, 모서리로 갈수록 타격 오프셋($-0.92 \sim +0.92$)에 따라 예리한 각도로 굴절되는 직관적인 조작감 구현
3. **4색 40개 컬러 벽돌 배치 & 점수 시스템**:
   - **레드 (1행)**: 40점
   - **골드 (2행)**: 30점
   - **그린 (3행)**: 20점
   - **블루 (4행)**: 10점
4. **절차적 8-bit 오디오 시스템 (`bevy_audio`)**:
   - `bounce.wav`: 벽 및 패들 튕김 480Hz 비프음
   - `break.wav`: 벽돌 파괴 시 750Hz $\rightarrow$ 1150Hz 상승 챠핑 효과음
   - `gameover.wav`: 하강 디센딩 톤 게임오버 사운드
5. **실시간 HUD & 목숨 게이지**:
   - 점수, 남은 목숨(`[♥♥♥]`), 남은 벽돌 수 및 현재 게임 상태를 맑은 고딕 한글 폰트로 상단에 실시간 표시
6. **헤드리스(Headless) 단위 테스트 100% 통과**:
   - 가변 반사각 수학 공식, 벽돌 충돌 및 점수 획득/소멸, Menu $\rightarrow$ Playing 상태 전이 자동 검증

---

## 🕹️ 조작 방법

| 입력 키 | 동작 |
| :--- | :--- |
| **A, D** / **방향키 (←, →)** | 패들 좌우 이동 |
| **Space** / **Enter** | 메뉴에서 게임 시작 / 일시정지 해제 / 재시작 |
| **P** | 게임 진행 중 일시정지 (Pause) 토글 |
| **R** | 게임오버 또는 클리어 시 즉시 새 게임 재시작 |
