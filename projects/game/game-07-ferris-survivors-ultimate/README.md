# Rust Game 07: Ferris Survivors Ultimate (100종 몬스터 도감 & 타이탄 보스전) 🦀⚔️

> **Bevy 0.20 기반의 상업용 인디 서바이벌 액션 완성작!**  
> 《디아블로》식 절차적 접두사(Affix) 엔진으로 탄생한 **100종의 다양한 몬스터 군집**, 제미나이 AI로 구현한 고품질 비주얼, **대시 회피 및 무적 프레임(i-frame)**, **플로팅 데미지 텍스트(FCT)**, **4종 무기 아스널**, 그리고 **90초 에픽 보스 레이드(타이탄 방사형 탄막)**를 탑재한 완성형 액션 게임입니다.

---

## 🎮 주요 핵심 시스템

1. **100종 몬스터 절차적 도감 & 기믹 엔진 (Monster Codex & Affix Engine)**
   - **10대 기본 종족**: 슬라임, 박쥐, 고블린, 스켈레톤, 거미, 골렘, 유령, 미믹, 흑마법사, 드래곤
   - **5대 원소 속성**: 일반, 화염(레드), 빙결(블루), 전격(옐로우), 심연(퍼플)
   - **8대 특수 접두사 변종(Affix)**:
     - `거대한`: 크기 1.6배, 체력 2.8배
     - `신속의`: 이동속도 +65%
     - `자폭하는`: 사망 시 광역 자폭 폭발
     - `분열하는`: 사망 시 미니 몬스터 2마리 분열
     - `방어막`: 첫 3회 타격 완전 무효화
     - `저격하는`: 2.8초마다 탄환 발사
     - `황금 럭키`: 대량 루비 보석 드랍
   - $10 \times 5 \times 8 = 400$가지의 완전히 유니크한 몬스터 조합이 실시간으로 출현하며, 머리 위에 고유 이름이 표시되고 처치 시 **도감(Bestiary)**에 자동 등록됩니다.

2. **제미나이 AI 비주얼 에셋 (Gemini AI Visuals)**
   - 영웅 갑옷을 입은 페리스(`hero_ferris`), 슬라임, 박쥐, 골렘, 메모리 리크 타이탄 보스(`boss_titan`), 고대 석재 바닥 타일(`arena_floor`), 루비 보석(`gem_ruby`), 타이틀 배너(`title_banner`) 8종 그래픽 연동.

3. **플레이어 대시(Dash) & 무적 프레임(i-frame)**
   - `[Shift]` 또는 `[Space]` 키 입력 시 순간 3.2배 속도로 고속 돌진
   - 0.18초간 **완전 무적(Invulnerable)**이 적용되어 적과의 접촉 충돌 데미지 100% 무효화
   - 대시 경로에 푸른색 잔상(Ghost Trail)이 생성되며 페이드아웃
   - 쿨다운: 1.6초 (HUD에 실시간 대시 상태 표시)

4. **플로팅 데미지 텍스트 (Floating Combat Text - FCT) & 15% 치명타**
   - 몬스터를 타격할 때마다 머리 위에 실시간 데미지 숫자가 포물선으로 튀어오르며 페이드아웃
   - 일반 타격: 노란색/흰색 텍스트 (`18`, `38`)
   - 치명타(15% 확률): 붉은색 대형 볼드 텍스트 (`CRIT! 76`) 및 전용 타격음(`crit_hit.wav`)

5. **4종 자동 무기 아스널**
   - **공전 궤도 칼날**: 플레이어 주변을 회전하며 근접 적 지속 절단
   - **유도 번개 화살**: 가장 가까운 적을 조준해 자동 저격
   - **성수 불꽃 장판**: 3초마다 적 무리에 성수를 던져 4초간 지면 화염 장판 형성 (초당 지속 틱뎀)
   - **관통 회전 도끼**: 위로 포물선을 그리며 높이 솟구쳐 화면 아래로 회전 낙하하며 경로상의 모든 적 관통

6. **90초 에픽 보스 레이드: 메모리 리크 타이탄 (Bullet Hell Boss)**
   - 생존 시간 90초(1분 30초) 도달 시 화면 붉은 플래시 점멸 및 보스 경보음(`boss_spawn.wav`)
   - 화면 상단에 **대형 보스 체력바(HP: 1400 / 1400)** 실시간 가시화
   - 보스는 4.2초마다 **8방향 방사형 쇼크웨이브 탄막**을 발사
   - 보스 격파 시 대폭발 80개 파티클 버스트 & 8개의 루비 보석 드랍!

7. **로컬 영구 세이브 및 몬스터 도감 통계**
   - 최고 생존 시간, 최다 킬 수, 그리고 **누적 발견한 몬스터 종류 수 (예: 64 / 100종 수집)**를 `assets/save/ultimate_records.json`에 영구 저장

## 🕹 조작 방법

| 키 입력 | 동작 |
| :--- | :--- |
| **`W, A, S, D`** 또는 **방향키** | 플레이어(페리스) 이동 (공격은 자동 발사!) |
| **`Shift`** 또는 **`Space`** | **고속 대시 회피 & 무적 프레임 (i-frame)** |
| **`Space`** | 시작 화면에서 전투 개시 |
| **`1` / `2` / `3`** | 레벨업 화면에서 3지선다 전설 스킬 선택 |
| **`R`** | 게임 오버 화면에서 전장 리셋 후 재도전 |
