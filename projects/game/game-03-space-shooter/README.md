# Rust Game 03: 탄막 슈팅 & AABB 충돌 감지 물리 💥🛸

Bevy 게임 엔진의 ECS 아키텍처를 활용하여 **AABB(Axis-Aligned Bounding Box) 2D 충돌 판정 물리**, 레이저 탄막 발사, 화면 밖 자동 소멸(Despawn) 및 별무리 패럴랙스 스크롤을 구현한 본격적인 우주 아케이드 슈팅 게임입니다.

---

## 🎮 주요 기능 및 학습 포인트

1. **AABB 2D 충돌 감지 알고리즘 (`Collider2d`)**:
   - 가로/세로 축에 정렬된 사각형 충돌 공식을 단순 사칙연산과 절대값(`abs()`)으로 초고속 연산
   - `intersects(pos_a, other, pos_b)` 메서드로 프레임당 수백 개의 탄환-적기 충돌을 병목 없이 처리
2. **트윈 레이저 발사 및 화면 밖 자동 소멸 (Despawn)**:
   - `Space` 키 입력 시 쿨다운 타이머(`WeaponCooldown`)에 맞춰 좌/우 듀얼 레이저 볼트 동시 발사
   - 화면 상단(+310px)을 벗어난 총알은 `commands.entity(e).despawn()`으로 즉각 메모리 해제
3. **주기적 적기(Enemy) 스폰 시스템**:
   - `EnemySpawnTimer`를 통해 0.75초마다 화면 상단 랜덤 X 좌표에 크림슨 레드 적기 생성
   - 적기가 플레이어와 충돌 시 쉴드(체력)가 감소하며, 쉴드가 모두 소모되면 Game Over 전환
4. **엔티티 안전 소멸 패턴 (`HashSet<Entity>`)**:
   - 한 프레임 내에서 동일한 엔티티가 다중 충돌하여 중복 despawn 패닉이 발생하는 것을 방지하는 집합 기반 안전 필터링
5. **무한 패럴랙스 별무리 배경 (Starfield)**:
   - 70개의 별들이 원근감에 따른 속도 차이로 하강하며, 화면 밖으로 벗어난 별을 상단으로 재배치하여 무한 순환
6. **실시간 HUD & 재시작 기능**:
   - 점수, 남은 쉴드량(`[███]`), 격추한 적기 수, 활성 레이저 탄환 수를 맑은 고딕 한글 폰트로 실시간 표시
   - Game Over 시 `R` 키를 눌러 즉시 점수와 쉴드를 초기화하고 재출격 가능
7. **헤드리스(Headless) 단위 테스트 100% 통과**:
   - AABB 충돌 수학 공식, 탄환-적기 충돌 및 점수 획득, 화면 밖 총알 소멸을 GPU 없이 메모리 상에서 초고속 자동 검증

## 🕹️ 조작 방법

| 입력 키 | 동작 |
| :--- | :--- |
| **W, A, S, D** / **방향키** | 플레이어 우주선 8방향 이동 (좌우 이동 시 롤 회전 애니메이션) |
| **Space (스페이스바)** | 트윈 레이저 탄막 연속 발사 |
| **R** | 게임 오버 시 쉴드 복구 및 게임 재시작 |
