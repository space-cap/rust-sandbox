# Rust Game 06: Ferris Survivors (2D 아레나 서바이벌 액션) 🦀⚔️

> **Bevy 0.20 기반의 6단계 대미를 장식하는 종합 실전 프로젝트: 뱀파이어 서바이벌(Vampire Survivors) 류 2D 탑다운 액션 게임**  
> 지금까지 학습한 **ECS 아키텍처, 스프라이트 프레임 애니메이션, AABB 물리 충돌, 상태 머신(States), 절차적 사운드, 그리고 게임 주스(파티클 버스트 & 트라우마 카메라 쉐이크)**를 한곳에 집대성한 완성형 게임입니다.

---

## 🎮 게임 특징 및 주요 시스템

1. **플레이어 페리스 (Ferris the Crab)**
   - 8-프레임 픽셀 아트 스프라이트 시트(`ferris_sheet.png`) 연동
   - 정지(Idle 0~3) $\leftrightarrow$ 이동(Run 4~7) 프레임 애니메이션 및 좌우 이동에 따른 자동 반전(`flip_x`)
   - 8방향 부드러운 이동 및 아레나 경계선 충돌 제한

2. **자동 무기 시스템 (Automatic Weapons)**
   - **공전 궤도 마법 칼날 (Orbiting Blade)**:
     - 플레이어 주변을 삼각함수($\cos \theta, \sin \theta$) 궤적으로 회전하는 마법 칼날
     - 적과 충돌 시 지속 타격, 스파크 파티클 비산 및 미세 쉐이크
     - 스킬 업그레이드를 통해 칼날 개수 추가 및 회전 속도 증폭
   - **최단 거리 적 자동 유도 번개 화살 (Homing Lightning Arrow)**:
     - 쿨다운 주기마다 사거리 내 가장 가까운 적을 자동 탐색하여 유도탄 발사
     - 적 명중 시 5개 파편 비산 및 타격 사운드(`arrow.wav`, `hit.wav`)

3. **군집 적 스티어링(Steering) AI 및 점진적 난이도**
   - 아레나 4방향 외곽에서 주기적으로 몬스터 스폰
   - 생존 시간이 길어질수록 스폰 주기 단축($1.0\text{초} \rightarrow 0.35\text{초}$) 및 몬스터 체력 점진 상승
   - 플레이어 위치를 향해 방향 벡터를 정규화하여 추적하는 벡터 스티어링 AI

4. **경험치 보석(Gem) 드랍 & 마그넷 인력 물리**
   - 몬스터 처치 시 85% 확률로 청록색 에메랄드 다이아몬드 보석 드랍
   - 플레이어가 마그넷 반경($120\text{px}$) 이내로 접근하면 플레이어를 향해 가속 비행하여 흡수
   - 보석 흡수 사운드(`gem.wav`) 및 EXP 게이지 충전

5. **4대 상태 머신(States) 및 3지선다 레벨업 카드 시스템**
   - `Menu`: 시작 안내 화면 (`[Space]` 키로 전투 개시)
   - `Playing`: 본 게임 전투 시뮬레이션
   - `LevelUp`: EXP $100\%$ 달성 시 전투 완전 일시정지, 5종 중 무작위 3장의 카드 출력
     - `[1]`: 마법 칼날 추가 (+1개 및 회전 속도 +20%)
     - `[2]`: 유도 번개 화살 쿨다운 30% 감소
     - `[3]`: 체력 즉시 +35 회복 및 최대 체력 +20
     - `[4]`: 경험치 자석 반경 +50px 확장
     - `[5]`: 이동 속도 +15% 증가
   - `GameOver`: 체력 소진 시 게임 오버 화면, 최고 기록 갱신 및 `[R]` 재도전

6. **로컬 영구 저장 (Data Persistence)**
   - 게임 종료 시 최고 생존 시간과 처치 수를 `assets/save/high_score.json`에 영구 기록
   - 다음 실행 시 자동으로 최고 기록을 불러와 비교 및 갱신

## 🕹 조작 방법

| 키 입력 | 동작 |
| :--- | :--- |
| **`W, A, S, D`** 또는 **방향키** | 플레이어(페리스) 이동 (공격은 자동 발사!) |
| **`Space`** | 시작 화면에서 전투 개시 |
| **`1` / `2` / `3`** | 레벨업 화면에서 스킬 카드 선택 |
| **`R`** | 게임 오버 화면에서 필드 리셋 후 재도전 |

## 🚀 실행 및 테스트

### 1. 단위 테스트 실행 (Headless Unit Tests)
```bash
cargo test -p game-06-survival-arena
```
- 2D AABB 충돌체 교차 판정 검증
- 적 스티어링 벡터 정규화 및 추적 거리 수렴 검증
- 궤도 칼날 삼각함수 좌표 계산 검증
- 플레이어 레벨업 임계치 및 스킬 업그레이드 수치 반영 검증
- `serde_json` 기반 로컬 최고 기록 영구 저장 및 복원 검증

### 2. 게임 실행
```bash
cargo run -p game-06-survival-arena
```
