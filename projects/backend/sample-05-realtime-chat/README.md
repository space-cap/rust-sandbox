# 💬 Sample 05: 실시간 웹소켓(WebSocket) 단체 채팅 서버

Tokio의 고성능 논블로킹 브로드캐스트 채널(`broadcast::Sender`)과 Axum의 `WebSocketUpgrade`를 활용하여 수만 명의 동시 접속자를 감당할 수 있는 실시간 단체 채팅 서버입니다.

---

## 📌 주요 학습 내용
1. **HTTP에서 WebSocket으로 프로토콜 업그레이드**: `WebSocketUpgrade`를 이용한 핸드셰이크
2. **1:N 논블로킹 팬아웃(Fan-out) 브로드캐스팅**: `tokio::sync::broadcast` 채널로 메시지 동시 전파
3. **소켓 스트림 분리**: `socket.split()`을 통해 송신(Send)과 수신(Receive) 태스크를 독립 분리하여 풀 듀플렉스(Full-Duplex) 통신
4. **접속 생명주기 관리**: 유저의 입장/퇴장 감지 및 자동 브로드캐스트 알림
5. **내장 웹 UI 제공**: 별도 프론트엔드 빌드 없이 브라우저에서 바로 열 수 있는 모던 다크 모드 채팅 웹 클라이언트

---

## 🏃‍♂️ 실행 방법

```bash
cargo run -p sample-05-realtime-chat
```
- 서비스 포트는 **3004** (`http://127.0.0.1:3004`) 입니다.

---

## 🌐 브라우저에서 직접 실시간 채팅해보기!

1. 브라우저(크롬, 엣지 등)를 열고 `http://127.0.0.1:3004`에 접속합니다.
2. 새 탭을 하나 더 열어 같은 주소(`http://127.0.0.1:3004`)로 접속합니다.
3. 탭 A에서는 닉네임 `페리스`, 탭 B에서는 닉네임 `러스티`로 각각 입장 버튼을 누릅니다.
4. 한쪽 탭에서 메시지를 전송하면 다른 쪽 탭에 **0.001초 만에 실시간으로 메시지가 전송**되는 것을 확인하실 수 있습니다! 🎉
