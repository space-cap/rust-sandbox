🪟 Windows SmartScreen & 코드 서명 (Code Signing)

보안 인증
1
SmartScreen 경고 원인: 마이크로소프트의 Authenticode 인증서로 서명되지 않았거나, 전 세계 다운로드 횟수(Reputation)가 축적되지 않은 신규 바이너리를 자동 차단합니다.
2
EV vs OV 인증서: EV(Extended Validation) 인증서로 서명하면 SmartScreen 경고가 즉시 해제되며, 하드웨어 토큰(HSM)이나 클라우드 서명(Azure Key Vault)으로 보호됩니다.
3
RFC 3161 타임스탬프: 인증서가 만료된 후에도 소프트웨어 배포 시점의 유효성을 영구 증명하기 위해 타임스탬프 서버를 필수 연동합니다.

🚀 전 플랫폼 크로스 컴파일 워크플로우 (.github/workflows/desktop-release.yml)

GitHub Actions

깃허브에 git tag v1.0.0 태그를 푸시하면 Windows, macOS, Linux 설치 파일이 동시 자동 빌드되어 Release 페이지에 등록됩니다.

name: Release Desktop App
on:
  push:
    tags: ['v*']

jobs:
  release:
    permissions:
      contents: write
    strategy:
      matrix:
        include:
          - platform: 'windows-latest'   # Windows NSIS (.exe) & WiX (.msi)
            args: '--target x86_64-pc-windows-msvc'
          - platform: 'macos-latest'     # macOS Apple Silicon & Intel (.dmg)
            args: '--target aarch64-apple-darwin'
          - platform: 'ubuntu-22.04'     # Linux (.AppImage, .deb)
            args: ''
    runs-on: ${{ matrix.platform }}
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: tauri-apps/tauri-action@v0
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          TAURI_SIGNING_PRIVATE_KEY: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY }}
        with:
          tagName: ${{ github.ref_name }}
          releaseName: 'App Release ${{ github.ref_name }}'
