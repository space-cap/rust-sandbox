Tauri 2.0 vs Electron 핵심 패러다임 비교

비교 항목 Electron (일렉트론) Tauri 2.0 (타우리 2.0)
웹뷰 엔진 Chromium 전체를 앱마다 번들링 (150MB+) OS 내장 웹뷰 활용 (WebView2 / WebKit) (15MB 미만)
메모리 점유율 기본 150MB ~ 500MB+ 30MB ~ 70MB (경량 최적화)
백엔드 런타임 Node.js 런타임 (런타임 오버헤드, GC 지연) 순수 네이티브 Rust (Zero-Cost Abstractions)
보안 모델 Node API 노출 시 XSS 시스템 침해 위험 Capabilities 명세서 기반 세분화 권한 격리
지원 플랫폼 데스크톱 (Win/Mac/Linux) 데스크톱 + 모바일 (Android, iOS) 단일 코드베이스

💡 Tauri 2.0의 3대 핵심 아키텍처 구성요소

  • Tao: 크로스플랫폼 윈도우 창 생성 및 마우스/키보드 이벤트 루프 관리
  • Wry: Windows WebView2, Mac WebKit을 동일한 Rust API로 추상화한 웹뷰 엔진
  • Tauri Core: IPC 직렬화 라우터, 상태 관리(tauri::State), Capabilities 보안 검증
