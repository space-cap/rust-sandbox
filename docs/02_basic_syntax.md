## 2.1 왜 기본이 불변(Immutable)일까? (`let`과 `mut`)

다른 프로그래밍 언어(JavaScript, Python, C++ 등)에서는 변수를 만들면 당연히 나중에 값을 바꿀 수 있는 경우가 많습니다.  
하지만 **Rust에서는 변수를 선언할 때 기본적으로 값을 변경할 수 없는 '불변(Immutable)' 상태**가 됩니다.

```rust
fn main() {
    let x = 5;
    println!("x의 값: {x}");

    x = 6; // ❌ 컴파일 에러 발생!
    println!("x의 값: {x}");
}
```

위 코드를 빌드하려고 하면 컴파일러가 강력하게 항의합니다:
```text
error[E0384]: cannot assign twice to immutable variable `x`
```

### 왜 기본을 불변으로 만들었을까요?
버그의 상당수는 **"여기서 값이 바뀔 줄 몰랐는데 저기서 몰래 바꿔버려서"** 발생합니다. 특히 멀티스레드 환경에서는 여러 작업이 동시에 값을 고치려다 시스템이 다운되기도 합니다.  
Rust는 **"기본은 절대 바뀌지 않게 두고, 정말 바꿀 필요가 있을 때만 명시하자"**는 철학을 따릅니다.

### 값을 바꾸고 싶다면? `mut` 키워드!
변수를 가변(Mutable)으로 만들려면 `let` 뒤에 **`mut`**을 붙여주면 됩니다.

```rust
fn main() {
    let mut x = 5;
    println!("변경 전 x: {x}");

    x = 6; // ⭕ 완벽하게 동작합니다!
    println!("변경 후 x: {x}");
}
```

## 2.2 변수 가리기(Shadowing)와 상수(const)

Rust에는 변수를 다루는 흥미롭고 강력한 두 가지 개념이 더 있습니다.

### 1. 변수 가리기 (Shadowing)
같은 이름의 변수를 `let`으로 다시 선언하는 것을 **새도잉(Shadowing, 가리기)**이라고 부릅니다.

```rust
fn main() {
    let spaces = "   "; // 공백 문자열 타입 (&str)
    let spaces = spaces.len(); // 숫자 타입 (usize)으로 재선언!

    println!("공백 개수: {spaces}"); // 출력: 공백 개수: 3
}
```

> [!NOTE]
> **`mut`과 섀도잉의 차이점**  
> `mut`은 **기존 변수의 값만** 바꿀 수 있고 타입은 바꿀 수 없습니다. 반면 **섀도잉은 새로운 변수를 만드는 것**이므로 값뿐만 아니라 **데이터 타입까지 자유롭게 변환**할 수 있습니다! 임시 변수 이름을 `spaces_str`, `spaces_num`처럼 지저분하게 늘리지 않아도 됩니다.

### 2. 상수 (const)
상수는 프로그램이 실행되는 동안 절대로 변하지 않는 고정된 값입니다.

```rust
const THREE_HOURS_IN_SECONDS: u32 = 60 * 60 * 3;
```
- 반드시 대문자와 언더스코어(`_`)로 이름을 짓는 관례가 있습니다.
- `let`과 달리 **반드시 데이터 타입을 명시**해야 합니다.
- 런타임이 아닌 **컴파일 타임에 계산 가능한 상수 표현식**만 대입할 수 있습니다.

## 2.3 핵심 데이터 타입 (스칼라 & 복합 타입)

Rust는 **정적 타입 언어(Statically Typed)**입니다. 컴파일 타임에 모든 변수의 타입이 정해져 있어야 합니다.  
다행히 대부분은 컴파일러가 알아서 타입을 똑똑하게 추론(Type Inference)해 줍니다.

### 1. 스칼라 타입 (단일 값을 담는 타입)

| 분류 | 타입 종류 | 설명 | 예시 |
| :--- | :--- | :--- | :--- |
| **부호 있는 정수** | `i8`, `i16`, `i32`, `i64`, `i128`, `isize` | 음수와 양수를 모두 표현. (기본값: `i32`) | `-42`, `1_000_000` |
| **부호 없는 정수** | `u8`, `u16`, `u32`, `u64`, `u128`, `usize` | 0 이상의 양수만 표현 (`u8`은 바이트 다룰 때 애용) | `100u8`, `404` |
| **부동 소수점** | `f32`, `f64` | 소수점을 가진 실수. (기본값: `f64`) | `3.14`, `0.001` |
| **불리언** | `bool` | 참 또는 거짓 | `true`, `false` |
| **문자** | `char` | 유니코드 1글자 (4바이트 크기, 작은따옴표) | `'A'`, `'한'`, `'🦀'` |

> [!TIP]
> 숫자 리터럴에 가독성을 위해 언더스코어(`_`)를 넣을 수 있습니다.  
> 예: `1_000_000` (백만), `1_000` (천)

### 2. 복합 타입 (여러 값을 하나로 묶는 타입)

#### 튜플 (Tuple)
서로 다른 타입의 값들을 고정된 길이로 묶을 수 있습니다.

```rust
fn main() {
    let tup: (i32, f64, char) = (500, 6.4, '🦀');

    // 구조 분해 (Destructuring)
    let (x, y, z) = tup;
    println!("z는 {z}"); // 출력: z는 🦀

    // 마침표(.)와 인덱스로 직접 접근
    println!("첫 번째 값: {}", tup.0); // 500
}
```

#### 배열 (Array)
**모든 요소가 같은 타입**이어야 하며, **길이가 고정**된 연속된 메모리 공간입니다.

```rust
fn main() {
    let months = ["1월", "2월", "3월", "4월", "5월"];
    let first = months[0];
    println!("첫 달은 {first}");
}
```
*(참고: 길이가 유동적으로 변하는 동적 배열은 표준 라이브러리의 `Vec<T>`(벡터)를 사용하며, 이는 03장과 04장에서 자세히 배웁니다!)*

## 2.4 함수와 표현식(Expression) vs 구문(Statement)

Rust의 함수는 `fn` 키워드로 선언하며, 매개변수와 반환값의 타입을 명시해야 합니다.

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b // 👈 세미콜론(;)이 없습니다! 왜일까요?
}
```

### 세미콜론의 비밀: 구문 vs 표현식
Rust는 **표현식 지향 언어(Expression-oriented Language)**입니다.

- **구문(Statement)**: 어떤 동작을 수행하지만, **값을 반환하지 않는 문장**입니다. 끝에 세미콜론(`;`)이 붙습니다.
- **표현식(Expression)**: 평가되어 **어떤 최종 결과값을 산출**하는 식입니다. 끝에 **세미콜론을 붙이지 않습니다!**

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1 // 블록의 마지막 줄에 세미콜론이 없으므로 4라는 값을 산출하여 y에 대입!
    };

    println!("y의 값: {y}"); // 4
}
```

> [!IMPORTANT]
> Rust 함수에서 `return` 키워드를 쓸 수도 있지만, 보통은 **함수의 맨 마지막 줄에 세미콜론 없이 표현식을 적는 것**이 관례적이고 권장되는 Rust 스타일(Idiomatic Rust)입니다!

## 2.5 흐름 제어 (`if`, `loop`, `while`, `for`)

### 1. `if` 조건문 (if도 표현식이다!)
조건식은 반드시 `bool` 타입이어야 합니다. (JS나 C처럼 0이나 null이 자동으로 거짓으로 취급되지 않습니다.)

```rust
fn main() {
    let number = 7;

    if number < 5 {
        println!("5보다 작습니다.");
    } else if number == 7 {
        println!("행운의 7입니다! 🍀");
    } else {
        println!("그 외의 숫자입니다.");
    }
}
```

`if`가 표현식이므로 삼항 연산자(ternary operator) 대신 변수에 바로 대입할 수 있습니다:
```rust
let condition = true;
let number = if condition { 5 } else { 6 }; // number는 5!
```

### 2. 반복문 삼총사

#### `loop` (무한 루프와 결과 반환)
`break` 뒤에 값을 적으면 루프를 빠져나오면서 그 값을 반환할 수 있습니다!

```rust
let mut counter = 0;
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // 루프가 끝나면서 20을 반환
    }
};
println!("결과: {result}"); // 20
```

#### `while` (조건부 루프)
```rust
let mut number = 3;
while number != 0 {
    println!("{number}!");
    number -= 1;
}
println!("발사! 🚀");
```

#### `for .. in` (가장 안전하고 빠른 권장 반복문)
인덱스로 인한 범위 초과 버그를 원천 봉쇄할 수 있어서 Rust에서 가장 많이 쓰입니다.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    for element in a {
        println!("값: {element}");
    }

    // 1부터 3까지 반복 (1..4)
    for number in 1..4 {
        println!("카운트: {number}");
    }
}
```
